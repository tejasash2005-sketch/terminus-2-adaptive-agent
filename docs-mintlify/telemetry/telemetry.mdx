---
title: "Usage stats"
description: "What Harbor collects and how to opt out."
---

Harbor collects limited usage telemetry to improve reliability and prioritize
development. It is enabled by default.

## Collected data

Harbor sends two events:

| Event | Data |
| --- | --- |
| `harbor.command_finished` | Runtime and platform, install and launch source, detected AI-agent label, CLI subcommand path, recognized option names, outcome, duration, job IDs, and exception type |
| `harbor.job_finished` | Job ID, agents and models, environment and resources, task and trial counts, enabled features, Harbor dataset references, Harbor package-task references, public Git repository references, outcome, token usage, cost, duration, reward, and exception type names |

## Not collected

- Raw commands or job configuration
- Local filesystem paths, private Git repository names, or custom registry locations
- Task instructions, prompts, or local task names
- Environment variables, agent or environment kwargs, or MCP configuration
- Artifact paths
- Exception messages or tracebacks
- Usernames, emails, or account identities

## Identity and delivery

Harbor creates a random installation ID in the user configuration directory.
It is not derived from account or machine identity.

Events are sent to PostHog by a detached process after the command returns.
Failed deliveries are dropped. Person profiles and GeoIP processing are
disabled.

The embedded PostHog project token is a public client-side event-capture token,
not a secret API credential. The maintainer has confirmed that the associated
project belongs to Harbor and is intended to remain in this release. This is a
maintainer confirmation; repository evidence does not independently verify
ownership against PostHog project settings.

## Opt out

```bash
HARBOR_TELEMETRY=off harbor run ...
```
