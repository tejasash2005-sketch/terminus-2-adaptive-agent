# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to tejasash2001@gmail.com.
Do not publicly disclose vulnerability details before the maintainer has had
an opportunity to investigate. This email address is the project's private
vulnerability-reporting contact for this release; it is not described as a
dedicated security service.

## Supported versions

Security fixes are expected to target the latest released version. Support for
older versions has not been established in this repository snapshot.

For the pending public release, the supported security profile is the default/core
dependency profile only. Optional extras (`huggingface`, `tinker`, `dspy`,
`adapter`, `blaxel`, `langsmith`, `gke`, `beam`, `computer-1`, `cloud`, and
`all`) and the development dependency group are not covered by a security-support
claim. Skypilot is early access and unsupported. See `FINAL_RELEASE_REVIEW.md`
for the advisory scope and remaining release limitations.
